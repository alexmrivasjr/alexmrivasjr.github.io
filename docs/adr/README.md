# Architecture Decision Records

Short documents that record a significant decision, the options weighed, and
the consequences. They're written when the decision is made, then left alone.
If a decision changes, a new ADR supersedes the old one.

Copy [`template.md`](template.md) to `NNNN-short-title.md` to add one.
